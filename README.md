# eMCQ Maker

বইয়ের পাতার ছবি থেকে AI (Google Gemini) দিয়ে ২-কলামের MCQ প্রশ্নপত্র ও উত্তরমালা (PDF) তৈরির ওয়েব অ্যাপ। পুরো ইন্টারফেস বাংলায়।

Build by **Jihad Junaed** — jihadjunaed1234@gmail.com

## কী কী পারে

- **ছবি বা PDF আপলোড:** একবারে সর্বোচ্চ ১০টি পাতা (JPG, PNG, WEBP অথবা PDF)। PDF-এর প্রতিটি পাতা ছবি বানিয়ে নেওয়া হয় (এজন্য ইন্টারনেট লাগে)।
- **দুটি মোড:**
  - *পাতায় ছাপা প্রশ্ন থেকে বাছাই* (ডিফল্ট): নতুন প্রশ্ন বানায় না। পাতায় ছাপা সাধারণ, বহুপদী সমাপ্তিসূচক ও উদ্দীপকভিত্তিক প্রশ্ন যেমন আছে তেমনই নেয়। প্রশ্নের পাশে উত্তর ছাপা থাকলে হুবহু সেটাই নেয় (আলাদা AI-পরীক্ষক পাতার সাথে মিলিয়ে দেখে)। কোনো প্রশ্নের উত্তর ছাপা না থাকলে PDF-এ **উত্তরমালা যোগ হয় না**।
  - *পাঠ থেকে নতুন প্রশ্ন বানানো:* পাতায় শুধু পাঠ থাকলে AI নতুন প্রশ্ন বানায় (সাধারণ, বহুপদী ও উদ্দীপক মিশিয়ে), প্রতিটির পক্ষে পাতার প্রমাণ খোঁজে এবং দ্বিতীয় AI দিয়ে উত্তর যাচাই করে।
- **সীমা:** বহুপদী ও উদ্দীপকভিত্তিক প্রশ্ন (প্রতিটির জন্য আলাদা) মোট প্রশ্ন অনুযায়ী সীমিত: ১০টি প্রশ্নে ০টি, ২০টিতে সর্বোচ্চ ২টি, ৩০টি বা বেশিতে সর্বোচ্চ ৫টি (মাঝের সংখ্যায় সমানুপাতিক)। বাকি সব সাধারণ প্রশ্ন। ছবিতে কাটা বা অসম্পূর্ণ প্রশ্ন নেওয়া হয় না, আন্দাজে পূরণও করা হয় না।
- **এলোমেলো সাজানো:** তিন ধরনের প্রশ্ন মিশিয়ে সাজানো হয়; উদ্দীপক সবসময় তার প্রশ্নের সাথে একসাথে থাকে।
- **AI বক্সে যেকোনো নির্দেশ (ঐচ্ছিক, ৮০০ অক্ষর):** প্রশ্নের ধরন/কাঠিন্য/ফোকাস এবং PDF-এর ফন্ট সাইজ, বোল্ড, লাইনের ফাঁক, এক বা দুই কলাম, অপশন সাজানো, অপশনের চিহ্ন (ক খ গ ঘ / a b c d), উত্তরমালা বাদ।
- **PDF:** A4, মাঝখানে শিরোনাম, ২ কলাম। ৩০টি পর্যন্ত প্রশ্ন এক পাতায় (ফন্ট ১১ থেকে ৬ পয়েন্টে নিজে ঠিক হয়), ৩০টির বেশি হলে পরের পাতায়। শেষে আলাদা উত্তরমালা পাতা (উত্তর থাকলে)।
- **হিস্টোরি:** আগের প্রশ্নপত্র ব্রাউজারে জমা থাকে (সর্বোচ্চ ৫০টি); আবার PDF নামানো যায়, AI-র কোটা খরচ হয় না।
- **ব্যবহার নির্দেশিকা:** সাইটের উপরের বাটন থেকে `public/eMCQ-Maker-User-Guide.pdf` খোলে।

## দরকারি Environment Variable

| নাম | মান |
|---|---|
| `GEMINI_API_KEY` | https://aistudio.google.com/apikey থেকে নেওয়া আপনার নিজের key (বাধ্যতামূলক) |
| `GEMINI_MODEL` | ঐচ্ছিক। ডিফল্ট `gemini-3.8-flash` |
| `GEMINI_FALLBACK_MODELS` | ঐচ্ছিক। মূল মডেল ব্যস্ত থাকলে কমা দিয়ে আলাদা করা বিকল্প মডেল |

key কখনো কোডে বা GitHub-এ লিখবেন না; শুধু Vercel-এর Environment Variables-এ বসাবেন।

## নিজের কম্পিউটারে চালানো (ঐচ্ছিক)

```bash
npm install
cp .env.example .env.local   # ভেতরে GEMINI_API_KEY বসান
npm run dev
```

## Vercel-এ Deploy

GitHub-এ repo বানিয়ে Vercel-এ **Add New → Project → Import** করুন, `GEMINI_API_KEY` বসিয়ে **Deploy** চাপুন।
পরে ফাইল বদলালে GitHub-এ একটাই commit-এ সব আপলোড করুন, Vercel নিজে নতুন করে Deploy করবে।

## ফোল্ডার

- `app/page.tsx` — মূল পাতা (ফর্ম, মোড, AI বক্স, হিস্টোরি)
- `app/api/generate-questions/route.ts` — Gemini দিয়ে প্রশ্ন বানানো/বাছাই ও যাচাই
- `app/api/parse-layout/route.ts` — AI বক্সের ফন্ট/স্টাইল নির্দেশ বোঝা
- `lib/pdf.ts` — PDF তৈরি; `lib/arrange.ts` — এলোমেলো সাজানো; `lib/gather.ts` — একাধিক অনুরোধে প্রশ্ন জড়ো করা
- `public/eMCQ-Maker-User-Guide.pdf` — ব্যবহার নির্দেশিকা
